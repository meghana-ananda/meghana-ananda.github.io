// Featured Work

Recent research & projects

Selected work from the UT Austin MS AI program.

01

LLM Memory Optimization — LoRA, QLoRA & 4-bit Quantization

Implemented four memory-efficient variants of a 73MB network from scratch (half-precision, LoRA adapters, 4-bit block quantization, QLoRA), with matched forward-pass outputs. Both LoRA and QLoRA converged within ~30 iterations on a 1000-sample classification task.

7×memory reduction
72→11MBmodel footprint
~30iters to converge
PyTorchLoRAQLoRAINT4
02

LLM Fine-Tuning — SFT, Chain-of-Thought & Rejection Sampling (RFT)

Fine-tuned SmolLM2-1.7B for unit conversion using SFT with LoRA adapters and batched generation with left-padding. Built an RFT data-generation pipeline (CoT sampling, correctness filtering) that outperformed vanilla SFT.

10–20×inference speedup
>90%RFT gen success
>0.85answer rate
SmolLM2HuggingFacePEFTRFT
03

LLM-Guided Robotic Manipulation

Closed-loop framework combining LLM symbolic reasoning with imitation-learned motor skills — ResNet-18 visual tokens and execution history fed to an LLM each step, with GRASP/MOVE_TO/PLACE policies trained via Behavior Cloning on Robomimic.

92 / 88 / 64%lift / place / stack
vs 18 / 16 / 4%LLM-only baseline
27.5→8.2decisions / episode
PyTorchPyBulletResNet-18Behavior Cloning
04

Autoregressive Image Generation with BSQ Tokenizer

Trained a patch-level autoencoder and Binary Spherical Quantizer (10-bit codebook), then a decoder-only Transformer with causal masking for next-token image generation, with autoregressive sampling of novel images.

~7×compression
500→76MBtokenized dataset
<4500bits / image CE
PyTorchTransformersBSQ
05

Computer Vision & NLP — CNN / U-Net / Transformer + ELECTRA / DAN

U-Net road detector and a Perceiver Transformer planner with learned waypoint queries for autonomous driving. ELECTRA-small fine-tuned on SNLI with contrast-set debiasing; a typo-robust DAN held accuracy on corrupted data with zero retraining.

>0.75segmentation mIoU
~89%SNLI accuracy
>74%robust on corrupted
